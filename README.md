# Forever Young Beauty by Layla

Website for Forever Young Beauty by Layla at Abshot Country Club, Titchfield Common, Fareham.

Live site: https://foreveryoungbeautybylayla.co.uk

## Deployment

- Framework: Astro
- Hosting: Cloudflare Pages, with static files generated by Astro
- Production branch: `main`
- Build command: `npm run build`; output directory: `dist`
- Node.js: 22.23.4 or newer (`.node-version` pins the Pages build version)
- Local checks: `npm ci`, then `npm run check`
- Local Pages preview: `npm run preview`
- Cloudflare configuration: `wrangler.json` for an assets-only deployment dry run; the existing Pages Git integration publishes `main`
- Sitemap: `https://foreveryoungbeautybylayla.co.uk/sitemap-index.xml`

## Main site areas

- Homepage: `/`
- Location: `/our-location/`
- Treatment landing pages: `/treatments/<treatment-name>/` (there is no `/treatments/` index)

All pages are prerendered. `src/middleware.ts` applies the shared HTML fixes during the build; it is not a production server. The generated `404.html` supplies missing-page responses, and `public/_headers` preserves response headers for Cloudflare Pages. No Cloudflare Astro adapter, runtime image optimizer, session binding, MDX or RSS integration is needed for this site.

The repository name is inherited from the original starter template; the live site is Forever Young Beauty by Layla.
