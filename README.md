# Forever Young Beauty by Layla

Website for Forever Young Beauty by Layla at Abshot Country Club, Titchfield Common, Fareham.

Live site: https://foreveryoungbeautybylayla.co.uk

## Deployment

- Framework: Astro
- Hosting/runtime: Cloudflare Workers
- Production branch: `main`
- Cloudflare configuration: `wrangler.json`
- Sitemap: `https://foreveryoungbeautybylayla.co.uk/sitemap-index.xml`

## Main site areas

- Homepage: `/`
- Location: `/our-location/`
- Treatment landing pages: `/treatments/`

The repository name is inherited from the original starter template; the live site is Forever Young Beauty by Layla.
